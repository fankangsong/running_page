## 修复首屏自定义字体加载导致的文字抖动（FOUT / 布局位移）

**根因**：字体通过 `src/main.tsx` 里的 `@fontsource/*` 引入。SPA 的 `#root` 在 React 挂载前为空，浏览器要等首屏出现文字才开始下载 woff2，所以字体请求永远晚于首屏绘制；再叠加 `font-display: swap`，系统字体先渲染 → 字体到达后替换 → Roboto Condensed 900 与系统 sans 宽度差异极大，大数字/标题明显重排。另外 fontsource 每个字重生成 5 条子集 @font-face（6 字重 = 30 条），还可能在 latin-ext 上多下载一次、多切换一次。

**方案（已落地）**：
1. 字体自托管：`src/assets/fonts/*.woff2`（6 个 latin 子集，从 node_modules 复制），`src/styles/fonts.css` 手写 6 条 @font-face，只保留 woff2。
2. `index.html` 加 4 个 `<link rel="preload" as="font" type="font/woff2" crossorigin>`（Roboto 400/500/700 + Roboto Condensed 900），字体发现提前到 HTML 解析阶段。
3. 首帧闸门：`<html class="fonts-pending">` + `#root{opacity:0}`；`src/utils/fontReady.ts` 主动 `document.fonts.load()` 关键 4 个字重，就绪（或 700ms 超时）后移除 class，内容 220ms 淡入；CSS 另有 2s 动画兜底防白屏。
4. 删除 main.tsx 里 6 个 `@fontsource` import（package.json 依赖暂留未删）。

**验证**：`pnpm build` 通过，产物 preload 被 Vite 改写为 `/running/assets/xxx-hash.woff2`；dev 环境 preload 与 CSS url 路径一致无重复下载；Chrome headless 截图确认首屏正常渲染、`<html>` 的 fonts-pending 已移除；tsc 对新增文件无报错（maps/RunDetail/utils 的既有错误与本次无关）。

**遗留**：`material-icons/iconfont/material-icons.css` 注册了 4 个图标字体家族（woff2 合计 600KB+），首页未使用图标，Tracks 等页用到；`font-display: block` + ligature，弱网会先闪图标名文字。如需可改为按需引入 filled.css 单家族。
